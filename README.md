# Time Simulator (Симулятор пространства-времени и световых конусов)

Интерактивный визуализатор течения времени, релятивистского запаздывания светового сигнала и пространства-времени Минковского.

## 🚀 Основные возможности

1. **3D Пространство-время (Диаграмма Минковского):**
   * Ось $Y$ — стрела времени $t$, горизонтальная плоскость $XZ$ — пространство.
   * Стек полупрозрачных слоёв-кадров времени.
   * Непрерывные «мировые трубки» (worldtubes) движущихся объектов.
   * 3D Световой конус прошлого (Past Light Cone), вершина которого находится в точке наблюдателя $(x_{obs}, y_{obs}, t_{now})$, а основание расширяется в прошлое со скоростью света $c$.
   * Полное 3D-управление камерой (вращение, зум, панорамирование).

2. **2D Взгляд наблюдателя (Срез светового конуса):**
   * То, что видит реальный наблюдатель на сетчатке/камере с учетом конечности скорости света ($t_{ret} = t - r/c$).
   * Визуализация эффекта Террелла — Пенроуза: видимое растяжение стержня при приближении и сжатие при удалении.
   * Переключение между релятивистским восприятием, абсолютным синхронным временем и режимом наложения.
   * Инструмент измерения кажущейся длины стержня ($L_{app} / L_0$).

3. **Редактор и таймлайн:**
   * Таймлайн с воспроизведением, паузой, покадровым шагом и регулятором скорости.
   * Готовые пресеты: «Летящий стержень», «Парадокс шеста и сарая», «Синхронизация вспышек».
   * Редактирование параметров объектов (скорость, размеры, положение, цвет).
   * Ползунок скорости света $c$ (от релятивистских скоростей до классической механики $c \to \infty$).

## 📁 Структура проекта

```
Time_simulator/
├── index.html              # Главная точка входа, разметка и импорты
├── start.bat               # Быстрый запуск сервера и открытие браузера
├── server.py               # Локальный HTTP-сервер с поддержкой ES-модулей
├── css/
│   └── style.css           # Тёмная современная тема, адаптивная сетка
├── vendor/                 # Локальные библиотеки (Three.js, OrbitControls)
└── js/
    ├── app.js              # Инициализация и координация приложения
    ├── core/
    │   ├── State.js         # Реактивное состояние и шина событий
    │   ├── ShapeModel.js    # Модели фигур, ключи анимации и пресеты
    │   └── SpacetimeMath.js # Формулы светового конуса, запаздывания и пересечений
    ├── renderers/
    │   ├── View3D.js        # Three.js 3D визуализация пространства-времени
    │   └── View2D.js        # Canvas 2D проекция наблюдателя и измерения
    └── components/
        ├── Timeline.js      # Таймлайн в стиле видеоредактора
        ├── Inspector.js     # Панель свойств объектов и физики
        └── Toolbar.js       # Верхняя панель управления и переключения видов
```

## 💻 Быстрый запуск

Дважды кликните `start.bat` (или запустите `python server.py`) и откройте `http://localhost:8000`.
